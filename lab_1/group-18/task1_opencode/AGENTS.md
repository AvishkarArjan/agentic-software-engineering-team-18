# Task 1 website rules

- Keep the website in one standalone `site/index.html` file (HTML, CSS, and JavaScript only).
- Load nothing from the internet: no CDN, remote fonts, images, scripts, or stylesheets.
- Include exactly the five members documented in `content/*.md`; use those files as the only source of member facts.
- Run the repository's `common/site_checker.py` against the finished site before completing work.
